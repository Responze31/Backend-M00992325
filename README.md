# Backend-M00992325
Backend for the project

## API Endpoints
- `GET /lessons` - Retrieve all after-school lessons
- `GET /search?q=query` - Search lessons across subject, location, price, and spaces
- `POST /orders` - Save a new order
- `PUT /lessons/:id` - Update lesson spaces or attributes
- `GET /enrolment/:lessonid` - Get total purchased slots for a lesson
- `GET /images/:filename` - Serve lesson images
